# Dota Arcade Host downloads

[Download the latest Windows installer](https://github.com/Scroatal/dotalauncher-releases/releases/latest)

Run the Setup EXE, then open **Join a friend**, paste your host's address or Steam link and choose **Join game**. You need Steam, Dota 2 and the same Workshop addon as your host.

Moving from the portable ZIP? Close the old launcher and run this installer once. Your saved servers and host settings carry over. Use the installed shortcut afterwards.

Installed copies check for updates on startup. Choose **Updates**, **Download update**, then **Install and restart** when ready. Stop any hosted server first. No GitHub account is required. Source pushes alone do not publish updates; a release must include the installer and update metadata.

This repository contains public downloads and update metadata. The Windows app is an unsigned preview. An upgrade between installed versions still needs a real Windows acceptance test.

Steam and Dota 2 are Valve products. This is an independent launcher, not an official Valve product.
